# هتل آوات اصفهان (Avat Hotel Isfahan)

وب‌سایت معرفی و رزرو مستقیم **هتل آوات اصفهان**؛ هتلی یک‌ستاره ممتاز در مرکز شهر، خیابان نشاط، کوچه شماره ۲۰، در شرق میدان نقش جهان.

این پروژه با تمرکز بر معرفی سریع هتل، نمایش تصویری فضاها، دسترسی آسان به اتاق‌ها و امکانات، و هدایت کاربر به تماس و استعلام رزرو طراحی شده است.

توسعه‌یافته بر پایه **Next.js (App Router)**، **TypeScript**، **Tailwind CSS v4** و کامپوننت‌های **shadcn/ui** با رعایت چیدمان راست‌به‌چپ (RTL) و فونت اختصاصی استعداد (Estedad).

## 🏛️ ویژگی‌های پروژه

- **طراحی تصویرمحور و مدرن:** معرفی هتل و فضاهای اقامتی با تمرکز بر تصاویر واقعی، موقعیت مرکزی و دسترسی به جاذبه‌های تاریخی اصفهان.
- **هویت بصری هتل آوات:** استفاده از ترکیب‌بندی آرام و حرفه‌ای برای انتقال حس اقامت شهری، دسترسی آسان و نزدیکی به میدان نقش جهان.
- **معرفی اتاق‌های واقعی هتل:** نمایش اتاق دوتخته برای یک نفر، دوتخته تویین، دوتخته دبل، سه‌تخته و چهارتخته؛ اغلب با اقامت همراه صبحانه.
- **مسیر مستقیم رزرو و اقدام (CTA):** هدایت کاربر به تماس با پذیرش، واتس‌اپ و استعلام ظرفیت و شرایط رزرو.
- **گالری عکس تعاملی با لایت‌باکس:** دسته‌بندی تصاویر فضاهای هتل و امکان مشاهده تصاویر در اندازه بزرگ با ناوبری راست‌به‌چپ.
- **نقشه تعاملی با Leaflet:** نمایش موقعیت هتل در خیابان نشاط و دسترسی به میدان نقش جهان، مسجد امام، مسجد شیخ لطف‌الله، کاخ عالی‌قاپو، کاخ چهل‌ستون، پل خواجو و سی‌وسه‌پل.
- **نمایش امکانات اقامت:** پذیرش ۲۴ساعته، آسانسور، سالن صبحانه، روم‌سرویس، لاندری، وای‌فای، تهویه مطبوع، یخچال، تلویزیون، چای‌ساز و پارکینگ سرپوشیده با ظرفیت محدود.

## 🛏️ انواع اتاق

- **اتاق دوتخته برای یک نفر:** یک تخت سینگل، مناسب اقامت یک نفر.
- **اتاق دوتخته تویین:** دو تخت سینگل، مناسب دو نفر.
- **اتاق دوتخته دبل:** یک تخت دبل، مناسب دو نفر.
- **اتاق سه‌تخته:** مناسب اقامت سه نفر.
- **اتاق چهارتخته:** مناسب اقامت چهار نفر.

جزئیات قیمت، ظرفیت، صبحانه و قوانین کنسلی باید هنگام انتخاب تاریخ از سامانه رزرو یا پذیرش استعلام شود.

## 📍 جاذبه‌های اطراف

موقعیت هتل امکان دسترسی پیاده یا کوتاه با خودرو به چند جاذبه مهم اصفهان را فراهم می‌کند:

- مسجد امام: حدود ۴۳۱ متر، ۵ دقیقه پیاده
- مسجد شیخ لطف‌الله: حدود ۵۱۶ متر، ۶ دقیقه پیاده
- میدان نقش جهان: حدود ۶۶۱ متر، ۸ دقیقه پیاده
- کاخ عالی‌قاپو: حدود ۶۹۷ متر، ۸ دقیقه پیاده
- کاخ چهل‌ستون: حدود ۲٫۵ کیلومتر، حدود ۵ دقیقه با خودرو
- پل خواجو: حدود ۲٫۴۸ کیلومتر، حدود ۴ دقیقه با خودرو
- سی‌وسه‌پل: حدود ۳٫۵۶ کیلومتر، حدود ۶ دقیقه با خودرو

## 🚀 راه‌اندازی محلی (Development)

برای اجرای پروژه در محیط لوکال:

```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه
npm run dev
```

سپس در مرورگر آدرس [http://localhost:3000](http://localhost:3000) را باز کنید.

## 📦 بیلد پروداکشن (Build)

```bash
npm run build
npm run start
```
