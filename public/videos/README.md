# فایل‌های ویدیوی عمودی هتل آوات (Reels / Video Stories)

این پوشه برای نگهداری ویدیوهای کوتاه عمودی (نسبت ۹:۱۶) وبسایت هتل آوات اصفهان است.

برای نمایش مستقیم ویدیوهای خود، فایل‌های ویدیویی (با فرمت `.mp4` ترجیحاً کدک H.264) را با نام‌های زیر در این پوشه قرار دهید:

1. `reel-1.mp4` : ویدیوی رقص نور ارسی‌ها و اتاق شاه‌نشین
2. `reel-2.mp4` : ویدیوی غروب و شب‌های حیاط مرکزی و حوض فیروزه‌ای
3. `reel-3.mp4` : ویدیوی صبحانه و خدمات روزانه هتل
4. `reel-4.mp4` : ویدیوی مسیر هتل تا جاذبه‌های اصفهان

> **نکته:** در صورتی که فایل‌ها هنوز اضافه نشده باشند، پوستر باکیفیت به صورت خودکار نمایش داده می‌شود و به محض افزودن ویدیوها، پلیر اختصاصی بدون نیاز به تغییر کد آن‌ها را پخش خواهد کرد.
